# Great Library AI

## Project Overview
A mystical, dark-themed AI chat interface called "The Great Library AI". The guardian eye (Eye of Providence inside a triangle) is the central visual element.

## Tech Stack
- Pure HTML/CSS/JS (single `index.html` file for now)
- No frameworks or build tools

## Design Language
- Dark background (#0a0a0a)
- Gold/amber accent color palette (#c8b88a, #3a3528, #5a5040)
- Serif fonts (Georgia)
- Mystical/ancient library aesthetic
- Input placeholder: "Speak unto the Guardian..."

## Key UI Elements
- **Eye of Providence**: SVG triangle with eye inside, animated:
  - Pupil tracks mouse cursor
  - Random blinking with occasional double-blinks
  - Breathing glow pulse
  - Ambient radial aura behind it
  - Floating particles around it
  - Brightens when input is focused
- **Input bar**: Bottom of screen, dark styled input with gold border
